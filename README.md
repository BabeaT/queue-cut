# queue-cut

> Monad Blitz 广州站 2026 参赛项目

**在以太坊上插队，钱给了矿工；在这里插队，钱给被你插队的每一个人。**

- 入队免费：每人自报「让位价」，也可以选「不让」。
- 补偿式插队：想往前插，就按被越过的每个人的让位价分别付钱，一笔交易给几十个人记账。
- 双方都消费才结算：插队者和被插者都完成消费，钱才归被插者；任何一方没消费，钱原路退回。
- 位置不能转让：黄牛要么白忙一场，要么变成真顾客。

运行在 Monad 测试网（Chain ID 10143）。完整方案见 [docs/PRD.md](docs/PRD.md)。
